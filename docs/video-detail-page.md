# 動画詳細ページ 設計ドキュメント

## 概要

| 項目 | 内容 |
|------|------|
| ページ | `/videos/[id]` |
| 目的 | 一覧で気になった動画の内容を詳しく見る |
| デザインイメージ | ミニマムな YouTube の動画詳細ページ |
| 対象デバイス | モバイル / タブレットを重視 |

## 目的

`/videos` の動画一覧ページで気になる動画を見つけたユーザーが、その動画の詳細情報を閲覧するためのページ。

ユーザーはこのページで：
- 動画の詳細な情報を確認できる
- 大きなサムネイル画像で動画の内容をイメージできる
- 一覧ページに戻ることができる

## 表示内容

### 必須要素

1. **一覧に戻る導線**
   - `/videos` への戻るボタン/リンク
   - 左上に配置（← 動画一覧に戻る）

2. **サムネイル表示**
   - 大きなサイズで表示
   - アスペクト比維持（16:9推奨）
   - 角丸処理
   - 将来の動画差し替えを考慮したレイアウト

3. **動画タイトル**
   - 明確な階層表示（h1）
   - 読みやすいフォントサイズ
   - 適切な行間調整

4. **動画説明文**
   - タイトル下に配置
   - 複数行対応
   - 読みやすい行間調整

### 追加表示要素（検討中）

- カテゴリ表示（videos.category）
- 作成日時表示（videos.created_at）

## データ仕様

### データソース
- Supabase の `videos` テーブルを使用

### 使用カラム
| カラム名 | 型 | 用途 | 必須 |
|----------|----|------|------|
| `id` | string | URLパラメータとのマッチング | ✅ |
| `title` | string | 動画タイトルの表示 | ✅ |
| `description` | string | 動画説明文の表示 | ✅ |
| `thumbnail` | string | サムネイル画像URL | ✅ |
| `category` | string | カテゴリ表示（オプション） | - |
| `created_at` | timestamp | 作成日時表示（オプション） | - |

### 制約
- 既存カラムのみ使用
- 新しいカラムの追加は禁止
- NULL値の適切なハンドリング

## UI/UX 設計

### レイアウト構成

```
┌─────────────────────────────────┐
│ ← 動画一覧に戻る                   │
│                                 │
│ ┌─────────────────────────────┐ │
│ │         サムネイル          │ │
│ │        (16:9推奨)          │ │
│ └─────────────────────────────┘ │
│                                 │
│ カテゴリ（オプション）             │
│                                 │
│ 動画タイトル                      │
│                                 │
│ 動画の説明文                      │
│ （複数行対応）                     │
└─────────────────────────────────┘
```

### レスポンシブ対応

#### モバイル（320px〜）
- コンテナ幅：全幅 - 左右パディング
- サムネイル：横幅100%
- テキスト：16px基準

#### タブレット（768px〜）
- コンテナ幅：最大幅設定（例：800px）
- サムネイル：横幅100%（コンテナ内）
- テキスト：18px基準

### ビジュアルスタイル

#### 全体方針
- 白背景を基調
- 余白多め（写真が主役）
- 角丸：大きめ（16px〜24px）
- 影：弱め（自然な立体感）

#### 各要素のスタイル
- **戻るリンク**: グレーテキスト、ホバー効果
- **サムネイル**: 角丸、影付き
- **タイトル**: 太字、適切なサイズ
- **説明文**: 読みやすいサイズと行間

## 技術仕様

### コンポーネント構造
```
VideoDetailPage/
├── BackLink (一覧に戻る導線)
├── ThumbnailDisplay (サムネイル表示)
├── VideoTitle (タイトル表示)
└── VideoDescription (説明文表示)
```

### データ取得
- Next.js App Router の動的ルートを使用
- Supabase クライアントでデータ取得
- 404エラーハンドリング（動画が存在しない場合）

### パフォーマンス考慮
- サムネイル画像の最適化（Next.js Image コンポーネント）
- 必要最小限のデータ取得
- モバイルファーストの読み込み
